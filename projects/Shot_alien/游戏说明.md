# 狙击外星人 — 网页版游戏说明

## 一、游戏概述

《狙击外星人》是一款第一人称狙击题材的网页射击游戏。玩家扮演一名精英狙击手，在多个场景中寻找并消灭隐藏的外星入侵者。

- **技术栈**：纯 HTML5 + CSS3 + JavaScript（Canvas 2D）
- **运行方式**：浏览器直接打开 `.html` 文件即可运行，无需任何依赖
- **当前版本**：v2.6
- **设计目标**：轻量、即开即玩、瞄准手感流畅、有层次感的游戏体验

---

## 二、设计思路

### 2.1 核心体验

游戏的核心乐趣来自三个环节构成的闭环：

```
搜索（Scan）→ 发现（Spot）→ 射杀（Shoot）
```

- **搜索**：在全景模式下观察场景，寻找外星人踪迹
- **发现**：切换到狙击镜，仔细观察场景中的异常（伪装的颜色、发光的眼睛）
- **射杀**：精确瞄准后果断开枪，获得分数反馈

### 2.2 双模式切换设计

参考手机版狙击游戏的节奏，游戏设计了两种视角模式：

| 模式 | 说明 | 作用 |
|------|------|------|
| **全景模式**（默认） | 宽视野俯瞰整个场景 | 用于侦查、定位、制定策略 |
| **狙击镜模式** | 放大瞄准镜视图，带 mil-dot 密位十字线 | 用于精确瞄准和射击 |

玩家通过 **T 键** 在两者间切换。每波开始时自动进入全景模式，强制玩家先观察再行动。

### 2.3 难度曲线

4 个关卡按难度递增排列：
1. **城市街道**（入门） — 建筑窗户多，外星人较显眼，含商店招牌细节
2. **公园绿地** — 树木和灌木丛增加遮挡
3. **森林深处**（高难度） — 密林环境，伪装色和阴影极多
4. **海滩海岸**（最终关） — 开阔地形，但外星人移动速度最快

每个关卡分 3 波，外星人数量逐波递增，移动速度也逐关加快。

### 2.4 外星人 AI 行为

- **拟态伪装**：外星人的颜色与所处环境的主色调接近（如城市关卡为灰色系，森林关卡为绿色系），仅在活动时会短暂降低透明度
- **周期性探头**：每个外星人有独立的 peek 动画周期，偶尔从藏身处探出
- **眼球发光**：外星人的眼睛会周期性发出黄色辉光，是玩家在狙击镜中发现目标的重要视觉线索
- **随机移动**：部分外星人会小范围缓慢移动，增加搜索难度
- **精灵图渲染**：支持加载外部图片（参考外星人.png）作为外星人外观，图片加载失败时自动回退到程序化绘制

### 2.5 视觉风格

- 暗色调夜间场景，营造狙击任务的沉浸氛围
- 狙击镜采用圆形遮罩 + 暗角 + mil-dot 密位十字线
- 击中反馈：粒子爆炸 + 浮动得分数字 + 音效
- 屏息时镜内晃动大幅减少，精度提升

## 三、操作说明

| 操作 | 全景模式 | 狙击镜模式 |
|------|----------|------------|
| **鼠标移动** | 环视场景 | 移动瞄准镜 |
| **滚轮** | 缩放视野（0.8x–1.8x） | 缩放倍率（2x–5x） |
| **左键点击** | — | **射击** |
| **T 键** | → 进入狙击镜 | → 返回全景 |
| **R 键** | — | 装弹 |
| **Shift（按住）** | — | 屏息稳定瞄准 |
| **Esc** | 打开设置菜单 | 打开设置菜单 |

### 按键速查

```
T       — 切换全景/狙击镜
鼠标左键 — 射击（仅在狙击镜内有效）
R       — 装弹
Shift   — 屏息（减少瞄准晃动）
滚轮    — 缩放
Esc     — 打开/关闭设置
```

## 四、游戏规则

### 4.1 计分

| 目标 | 基础分数 | 说明 |
|------|----------|------|
| 普通外星人（黄色显眼） | 100 分 | 较容易发现 |
| 伪装外星人（与环境同色） | 200 分 | 更难发现，击杀奖励更高 |

### 4.2 连击系统

连续命中外星人可累积连击数，获得分数加成：

```
连击 1 → ×1.0 倍
连击 2 → ×1.5 倍
连击 3 → ×2.0 倍
连击 4 → ×2.5 倍
连击 5+ → ×3.0 倍（上限）
```

脱靶或未命中则连击归零。

### 4.3 生命与失败条件

- 初始 **5 条命**（❤ 显示在右上角）
- 每脱靶 **5 次** 扣除 1 条命
- 命数为 0 时游戏结束
- 消灭当前波次所有外星人即可进入下一波/下一关
- 通过全部 4 关即为胜利
- 游戏结束时可选择 **重来当前关**（不重置进度）或 **返回主页**

### 4.4 弹药与装弹

- 弹匣容量 **8 发**
- 打空后自动装弹，也可按 **R 键** 手动装弹
- 装弹耗时 **1.5 秒**
- 弹药不足时屏幕下方会显示红色装弹提示

### 4.5 屏息机制

- 在狙击镜内按住 **Shift** 可屏息
- 屏息时瞄准镜晃动大幅减少，精度提升
- 屏息持续时间约 **3.5 秒**，松开后缓慢恢复

## 六、设置系统（v2.6 新增）

点击右上角 `*` 按钮或按 **Esc** 打开设置面板：

- **音效开关**：控制游戏内所有音效的播放
- **震动反馈**：命中目标时触发设备震动（需设备支持）
- **继续游戏**：关闭设置返回游戏
- **重来当前关**：从当前关卡第一波重新开始
- **返回主页**：退出当前游戏回到主菜单

点击右上角 `?` 按钮可打开帮助面板（预留支付接口）。

## 七、技术实现

### 7.1 坐标系

```
关卡数据坐标系: 1200 × 800 px（便于人工编辑）
游戏世界坐标系: 2400 × 800 px（由关卡数据按比例放大）
屏幕坐标系:    视口实际像素
```

转换公式：

```javascript
// 世界坐标 → 屏幕坐标
sx = (wx - camera.x) * zoom + W/2
sy = (wy - camera.y) * zoom + H/2

// 屏幕坐标 → 世界坐标
wx = (sx - W/2) / zoom + camera.x
wy = (sy - H/2) / zoom + camera.y
```

### 7.2 相机系统

- 鼠标位置映射到世界坐标，控制相机目标位置
- 使用线性插值实现平滑跟随（全景模式 lerp=0.1，狙击镜模式 lerp=0.3）
- 狙击镜模式下有更紧的边界 padding（0.05 vs 0.5），防止镜头出界

### 7.3 狙击镜渲染

1. 全屏黑色遮罩
2. 圆形裁剪区域（半径 = min(W,H) × 0.42）
3. 在裁剪区域内绘制世界场景（带 zoom 缩放）
4. 叠加 scope 外环和密位十字线
5. 绘制中心红点
6. 开枪时显示枪口火焰动画

### 7.4 音效系统

使用 Web Audio API 程序化生成音效，无外部音频文件依赖：
- **枪声**：锯齿波频率下降 + 白噪声爆音
- **命中**：正弦波上升再下降
- **惨叫**：双振荡器 + 噪声的三层混合
- **脱靶**：短促低音
- **装弹**：三次快速方波咔嗒声
- **连击**：高音双音
- **失败/胜利**：下行/上行琶音

### 7.5 波次切换机制（v2 重构）

波次过渡使用帧计数计时器而非 setTimeout 回调：

1. 最后一个外星人被击杀时设置 `waveCleared = true`，启动 30 帧倒计时
2. 倒计时结束后调用 `clearWave()`，增加波次
3. 新波次启动 50 帧延迟后调用 `spawnAliens()`
4. 包含调试日志输出，便于排查波次切换问题

### 7.6 外星人生成

- 根据关卡数据（建筑、树木、灌木）动态计算所有可能的藏身点
- 从藏身点池中随机选取，确保每次游戏分布不同
- 外星人的颜色从关卡调色板中选取，最后一个颜色固定为显眼的黄色（"easy alien"）

## 八、优化与版本历史

### v1.0（初始版本）
- 基础游戏框架：Canvas 渲染、相机系统、外星人生成
- 6 个关卡场景
- 单一狙击镜模式（无全景）

### v1.1（双模式重构）
- 新增全景模式，进入游戏时默认全景视图
- 新增外星人信号指示圈（脉冲虚线圆环）
- 按 T 切换全景/狙击镜
- 波次切换时自动回到全景模式
- 添加外星人惨叫音效

### v1.2（稳定性增强）
- 主循环包裹 try-catch，防止单帧错误导致整体卡死
- 添加 window.onerror 全局错误捕获
- 遍历方式优化：倒序索引 + splice，避免并发修改异常
- 相机边界 clamping 强化，防止 NaN 传播

### v2.6（当前版本）
- 新增设置面板：音效开关、震动反馈、继续/重来/返回主页
- 新增帮助面板（预留微信/支付宝支付接口）
- 波次切换系统重构：帧计数计时器替代 setTimeout
- 外星人数量使用显式计数器（aliensRemaining）替代数组轮询
- 支持精灵图渲染（参考外星人.png），失败自动回退程序化绘制
- 新增设备震动反馈（navigator.vibrate）
- 关卡数据重构：简化为 4 关，新增建筑商店/屋顶属性
- 相机系统优化：模式独立 lerp 速度和边界 padding
- 渲染函数拆分：drawBuilding/drawTree/drawBush 独立函数
- 移除水面渲染、远景山脉、星空等场景元素
