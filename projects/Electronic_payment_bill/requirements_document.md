# 电子支付智能账本助手 - 需求分档文档

## 1. 项目概述

### 1.1 项目背景
为用户提供一个离线/本地运行的电子支付账本工具，通过导入微信、支付宝、银行卡等支付流水截图（主要方式）或文件（备选方式），自动生成月度花销账本，帮助用户管理个人财务。

### 1.2 核心目标
- 隐私保护：完全本地运行，数据不上传云端
- 图片识别：支持支付流水截图的智能识别（主要方式）
- 文件导入：支持CSV/Excel文件导入（备选方式）
- 流水整合：支持多平台支付流水导入与合并
- 智能分析：自动生成月度账单和消费建议
- 灵活导出：支持多种格式本地保存

## 3. 功能模块划分

### 3.1 图片识别模块（主要）
- 支持拖拽上传或点击选择截图图片
- 支持JPG、PNG、WEBP等常见图片格式
- 使用本地OCR引擎识别图片中的文字信息
- 智能解析微信、支付宝、银行卡流水格式
- 支持批量上传多张截图

### 3.2 文件导入模块（备选）
- 支持拖拽上传或点击选择文件
- 自动识别文件格式（CSV/XLS/XLSX）
- 解析微信、支付宝、银行卡流水格式

### 3.3 数据处理模块
- OCR结果解析与提取
- 交易时间、金额、描述等字段识别
- 重复交易检测与合并
- 消费分类自动识别
- 数据清洗与标准化

### 3.4 编辑修正模块
- 识别结果预览与确认
- 手动编辑交易信息
- 删除错误识别记录
- 添加手动录入交易

### 3.5 账单展示模块
- 月度切换按钮（支持上一月/下一月）
- 手动输入月份功能（支持快速定位历史月份）
- 消费列表展示
- 分类统计展示
- 可视化图表

### 3.6 导出模块
- 支持格式：MD、CSV、JSON
- 自定义导出内容
- 一键保存到本地

### 3.7 总结分析模块
- 月度消费总结生成
- 智能消费建议
- 消费趋势分析

## 4. 技术方案

### 4.1 技术栈
- **前端框架**: 原生HTML + CSS + JavaScript（无需第三方框架，保证轻量）
- **图表库**: Chart.js（轻量级图表库）
- **OCR引擎**: Tesseract.js（纯前端OCR，离线运行）
- **文件处理**: PapaParse（CSV解析）、SheetJS（Excel解析）
- **样式**: TailwindCSS 3.x（快速构建UI）

### 4.2 数据存储
- 浏览器本地存储（LocalStorage）
- 支持数据导出为JSON格式备份

### 4.3 核心算法
- **OCR识别**: 使用Tesseract.js进行图片文字识别
- **流水解析**: 基于正则表达式匹配交易时间、金额、描述
- **重复检测算法**: 基于交易时间、金额、描述相似度匹配
- **分类识别算法**: 关键词匹配+规则引擎

## 5. 数据格式规范

### 5.1 识别字段标准
| 字段 | 说明 | 示例 |
| :--- | :--- | :--- |
| 交易时间 | yyyy-MM-dd HH:mm:ss | 2024-01-15 14:30:00 |
| 交易类型 | 收入/支出 | 支出 |
| 金额 | 数字（保留2位小数） | 58.50 |
| 描述 | 交易备注/商户名 | 美团外卖 |
| 渠道 | 微信/支付宝/银行卡 | 微信 |

### 5.2 消费分类标准
| 分类 | 关键词示例 |
| :--- | :--- |
| 餐饮 | 外卖、餐厅、超市、零食、美团、饿了么 |
| 交通 | 地铁、公交、滴滴、高德、加油、停车 |
| 购物 | 淘宝、京东、拼多多、天猫、超市 |
| 娱乐 | 电影、游戏、KTV、视频会员、音乐 |
| 医疗 | 医院、药店、体检、挂号、医保 |
| 教育 | 课程、书籍、培训、考试、学习 |
| 居住 | 房租、水电、物业、维修、家具 |
| 其他 | 默认分类 |

### 6.2 交互流程（图片识别方式）
1. 用户上传支付流水截图（可多张）
2. 系统使用OCR识别图片中的交易信息
3. 显示识别结果预览，用户可编辑修正
4. 用户确认导入，系统合并重复记录
5. 用户选择查看月份（点击箭头或直接输入年月）
6. 系统展示月度账单
7. 用户可导出账单或查看总结建议

### 6.3 交互流程（文件导入方式）
1. 用户上传CSV/Excel流水文件
2. 系统解析文件内容
3. 显示解析结果预览，用户可编辑修正
4. 用户确认导入，系统合并重复记录
5. 用户选择查看月份（点击箭头或直接输入年月）
6. 系统展示月度账单
7. 用户可导出账单或查看总结建议

## 7. 初版效果优化建议

### 7.1 人性化设计
- **智能提示**: 上传图片时提示支持的格式和最佳拍摄建议
- **操作引导**: 首次使用时显示操作指引，包含截图示例
- **错误处理**: OCR识别失败时给出具体错误原因和建议
- **加载状态**: OCR处理时显示进度条和预计时间
- **识别准确率显示**: 显示识别准确率，提醒用户核对

### 7.2 用户体验提升
- **批量上传**: 支持同时上传多张流水截图
- **截图裁剪**: 支持对图片进行裁剪，只保留流水区域
- **手动录入**: 支持手动添加交易记录
- **搜索过滤**: 支持按关键词搜索交易记录
- **数据缓存**: 自动保存已识别的数据

### 7.3 视觉设计
- **响应式布局**: 适配不同屏幕尺寸
- **主题切换**: 支持深色/浅色模式
- **动画效果**: 平滑过渡和微动画
- **图标系统**: 使用直观的图标表示分类
- **卡片式设计**: 清晰的信息层级

### 7.4 OCR识别优化
- **格式适配**: 支持微信、支付宝、各大银行不同版本的流水样式
- **自动纠偏**: 自动修正倾斜的截图
- **区域识别**: 智能识别流水表格区域
- **多语言支持**: 支持中英文混排识别

## 8. 安全性考虑

### 8.1 隐私保护
- 纯前端实现，数据不上传服务器
- OCR识别完全在本地进行，图片数据不传输
- 不收集任何用户个人信息
- 定期清理浏览器缓存提示

### 8.2 数据安全
- 支持数据加密存储（可选）
- 导出文件包含校验信息
- 提醒用户妥善保管本地文件
